# Use with Codex or another coding agent

Open this repository as the working directory and have the agent read `AGENTS.md`, `README.md` and `SECURITY.md`. Invoke the CLI through ordinary terminal tools. No MCP server or separately installed Skill is required.

## Suggested task

> Prepare a JevRail job using only the synthetic example. Inspect the input and run `./jevrail plan` first. Show the item count, data scope and local budget. Do not make a live call without my authorization. Once authorized, retain the raw provider responses and actual costs, and stop rather than resending an uncertain request. Label your interpretation separately from Jev's output.

This text is a usage example, not a privileged instruction. The user's instructions and the host's security policies control execution.

For a real job, agree on the rubric, evidence, data disclosure and cost before running. The agent should not manufacture missing observations or confuse synthetic connectivity checks with real media scoring.

After a run, report completed/pending/uncertain counts, observed cost and receipt location. An `uncertain` attempt means the outcome or cost needs inspection; it is not permission to retry in a fresh directory.
