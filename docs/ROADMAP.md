# Roadmap

These are directions, not release commitments.

## Keep the first release small

- A readable macOS CLI for Jev decisions through OpenRouter.
- Clear credentials, spend and evidence boundaries.
- Offline regression tests and a reproducible source release.

## Next, if user reports justify it

- A fully offline receipt-verification command for third-party inspection.
- A guided reconciliation flow for uncertain calls that never silently resends.
- A secure credential interface for Linux and Windows, tested on each platform.
- Reviewed model-snapshot upgrades and explicit schema compatibility.
- Optional redacted, shareable receipt exports with precise provenance labels.

## Outside the current scope

A general autonomous-agent framework, full media analysis, a hosted proxy, arbitrary model execution, and claims of certified safety or calibrated model accuracy.
