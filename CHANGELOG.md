# Changelog

## 0.1.0-alpha.1 — prepared for initial release

- Direct OpenRouter Jev decisions from a TypeScript CLI, with zero runtime npm dependencies.
- Explicit macOS Keychain selectors, a fixed HTTPS destination, and inert typed results.
- Persisted budget reservations, bounded concurrency, conservative retry handling, and verified cache reuse.
- Separate original response bytes, parsed answers, reported usage and local interpretation.
- English / Chinese guides, offline regression tests, and a source publication checker.

No general chat, media upload, Windows credential support, automatic billing reconciliation, or security certification is claimed.
